# Demonstration script (3–5 minutes)

Record an honest live demonstration using the packaged build where practical. A timestamped screenshot walkthrough with logs is acceptable as an equivalent alternative according to the assignment.

| Time | Demonstration | What to show |
|---|---|---|
| 0:00–0:25 | Launch | Start from extracted folder using `Launch.exe`; show no terminal/install/build required |
| 0:25–1:00 | Geometry | Load ASCII STL, orbit/pan/zoom/fit; load synthetic CSV, show units/legend/node inspection |
| 1:00–1:50 | Thermal | Run N=10,20,40,80; show temperature/exact curves, midpoint errors and convergence; export CSV |
| 1:50–2:40 | Performance | Show seed/workload; run serial and parallel; display worker counts, five reps, median, speedup/efficiency and agreement |
| 2:40–3:25 | Hardware | Show all three simulated devices, capabilities, telemetry; inject timeout and recover |
| 3:25–4:10 | Backprop | Show forward values, four gradient checks, simultaneous update and loss curve |
| 4:10–4:40 | Delivery | Show README/report, tests, results, AI-use log and limitations |

Adjust timing to 3–5 minutes. Do not include a claim that was not demonstrated or supported by an included log/test.

## Timestamped screenshot-walkthrough alternative

If recording video is not possible, include screenshots with filenames such as `01_launch.png`, `02_stl.png`, `03_temperature_cloud.png`, `04_fea.png`, `05_benchmark.png`, `06_hardware_timeout_recovery.png`, `07_backprop.png`, and `08_package_contents.png`. Add a text log with timestamp, action, expected behavior and actual result. Do not fabricate timestamps.
